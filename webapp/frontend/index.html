How it works

  1. Your image is sent to a backend running a trained YOLO11-seg model (best.pt).
  2. The model predicts pixel-accurate crack masks (segmentation, not just boxes).
  3. All predicted masks are merged and rendered as a semi-transparent fill plus a crisp contour outline directly onto your original image.
  4. You get back the overlay image and a count of detected crack instances.

About this project

Matanglawin 2.0 is built around a YOLO11-seg model for crack segmentation, originally driven by a local script (infer_overlay.py) that asks for an image and saves an overlaid result. This website exposes the exact same detection logic through a simple browser UI backed by a FastAPI service.
